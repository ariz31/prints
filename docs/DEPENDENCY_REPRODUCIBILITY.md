- Real lockfile v3 generated by npm 11.9.0 on Node 24.22.1; a clean `npm ci --ignore-scripts` succeeded without regenerating the lock. Runtime/build metadata is pinned to Node 24.x so a new Node major cannot silently change the release environment.
- `scripts/check-dependencies.mjs` computes and logs the current `package-lock.json` SHA-256 during every build, avoiding a stale hand-maintained checksum.
- `npm audit --json` and `npm audit --omit=dev --json`: zero known advisories for this tree. Run again when dependencies change.
- `scripts/check-dependencies.mjs` enforces direct dependency equality, registry provenance and recorded integrity for every lock entry. `npm ci` verifies package integrity and refuses manifest drift.
- Vercel install command: `npm ci --ignore-scripts`. The package-manager metadata records `npm@11.9.0`; installed tree is dictated by the lock. No post-install scripts are needed for the tested build.

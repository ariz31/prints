The font filenames include a prefix of each original blob identifier. If a font
changes, give its replacement a new catalog ID and filename, and retain the
old entry and file. This preserves saved projects and lets an old open tab load
its matching version from the retained offline cache. Font coverage and complex text shaping still depend on
the font and the rendering engine; the catalog does not imply universal glyph
or language support.
